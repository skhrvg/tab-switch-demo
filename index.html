Переключение между приложениями без дублей вкладок

Пять приложений на одном домене. Переключатель открывает приложение в новой вкладке, а если его вкладка уже есть — переходит на неё, не перезагружая.

Что проверить

  1. Возврат без перезагрузки. Откройте «Заметки», напишите текст, перейдите в «Счётчик» и вернитесь через переключатель. Текст на месте, время загрузки в карточке «Эта вкладка» прежнее.
  2. Закрытая вкладка. Закройте вкладку приложения и перейдите в него снова — откроется новая.
  3. Независимая вкладка. Скопируйте адрес приложения и откройте его вручную в новой вкладке. В переключателе появится пунктирная отметка «открыто отдельно», а переход создаст ещё одну вкладку: искать вкладки по имени браузер разрешает только среди связанных.

Как это устроено

// при загрузке каждого приложения
window.name = 'tabdemo-notes';

// переход — только из обработчика клика
function switchTo(name, url) {
  const tab = window.open('', name);        // найденная вкладка не перезагружается
  if (tab.location.href === 'about:blank') {
    tab.location.href = url;                // вкладки не было — загружаем приложение
  }
  tab.focus();
}

Полная версия с обработкой блокировщика всплывающих окон — в shared/shell.js.
