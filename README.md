# Переключение между приложениями без дублей вкладок

Демо: пять приложений на одном домене и общий переключатель. Он открывает приложение в новой вкладке, а если вкладка этого приложения уже есть, переходит на неё без перезагрузки.

**Открыть:** https://skhrvg.github.io/tab-switch-demo/

## Как это работает

Каждое приложение при загрузке задаёт вкладке постоянное имя, а переход идёт через `window.open('', имя)`: браузер возвращает уже открытую вкладку с таким именем или создаёт новую пустую.

```js
window.name = 'tabdemo-notes';

function switchTo(name, url) {
  const tab = window.open('', name);        // найденная вкладка не перезагружается
  if (tab.location.href === 'about:blank') {
    tab.location.href = url;                // вкладки не было — загружаем приложение
  }
  tab.focus();
}
```

Вся логика лежит в [`shared/shell.js`](shared/shell.js).

## Ограничения

- Браузер ищет вкладку по имени только среди связанных: тех, что открыты друг из друга через `window.open`. На вкладку, которую пользователь открыл вручную, переключиться нельзя. Демо показывает такие вкладки отметкой «открыто отдельно» (они находятся через `BroadcastChannel`) и открывает ещё одну.
- Связь рвут `rel="noopener"`, параметр `noopener` в `window.open` и заголовок `Cross-Origin-Opener-Policy: same-origin`.
- Переход нужно вызывать из обработчика клика, иначе сработает блокировщик всплывающих окон.
